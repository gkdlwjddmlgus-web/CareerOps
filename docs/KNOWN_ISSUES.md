# 남은 검증과 알려진 제한

확인일: 2026-11-20.

- Android 실기기가 연결되지 않았다. APK 설치/업데이트 데이터 유지, 시스템 뒤로 가기,
  큰 글자·다크 모드 시각 QA, 실제 파일 선택, 알림 표시·탭·재부팅은 NOT RUN이다.
- 공식 Android 36 에뮬레이터를 설치했으나 하이퍼바이저 드라이버 미설치로 기본 실행이 거부됐다.
  시스템 설정을 바꾸지 않는 TCG 소프트웨어 실행도 시도했으나 검증 가능한 온라인 기기를 확보하지 못했다.
- 로컬 알림은 inexactAllowWhileIdle 방식이다. Android 절전 정책에 따라 지연될 수 있다.
  권한 철회 시 예약은 해제하고 원본 일정은 유지한다. 권한을 다시 허용한 뒤 재예약해야 한다.
- 학습 시간의 일/주간 집계는 학습 시작일 기준이다. 자정을 넘는 기록을 임의로 분할하지 않는다.
- 과목에 학습 기록이나 진행 타이머가 있으면 삭제하지 않는다. 관련 기록을 보호하기 위한 정책이다.
- 서명키와 signing.properties는 저장소 밖 private-signing 폴더에 있다. 이후 APK 업데이트에도 같은 키가 필요하다.
  키를 GitHub·공개 릴리스·소스 ZIP에 넣지 않는다.
- main 반영·v0.1.0 태그·GitHub Release는 기기 검증과 릴리스 기준선 확인 전에는 진행하지 않는다.
