# CareerOps 0.1.0 요구사항

한국어 개인용 Android 공부·취업 통합 관리 앱. Flutter/Dart, Material 3,
Riverpod, Drift/SQLite, go_router, 로컬 알림, JSON 백업을 사용한다.

하단 탭은 홈·학습·취업·일정·리포트이며 설정은 홈에서 진입한다.
필수 범위는 할 일 및 일정 CRUD, 과목·단원, 재시작 가능한 타이머,
수동 학습 기록, 기업·지원 상태와 이력, 알림, 백업·복원이다.
실제 DB를 기반으로 주간 시간·완료율·지원 통계를 계산한다.

Application ID: `com.careerops.planner`. 기존 LifeOps와 데이터는 수정하지 않는다.
날짜는 YYYY-MM-DD, 시각은 UTC ISO 8601, 학습 시간은 초로 저장한다.
지원 상태 변경과 복원은 트랜잭션으로 처리한다.
진행 중인 타이머는 완료 학습 세션과 분리한다.

제외: 로그인, 클라우드 동기화, AI 계획, 채용 수집, 외부 API, 수익화, 게임화.

## 개발 및 검증

1. 초기화: 테마, 라우팅, 5개 탭, DB. 분석·탭 위젯·DB 초기화 테스트.
2. 할 일/일정: 저장·완료·정렬·홈/캘린더 일치 테스트.
3. 학습: 과목/단원·타이머·수동 기록, 재시작 및 시간 계산 테스트.
4. 취업: 기업·상태 이력, 원자성 및 마감일 테스트.
5. 알림/백업: 권한 거부·예약 실패, 손상 파일 거부 및 무결성 테스트.
6. 리포트/QA: 실제 DB 통계, 전체 분석·테스트·릴리스 APK 빌드.

Phase별 검증 통과 후 develop에 Conventional Commit으로 커밋·푸시한다.
검증되지 않은 코드는 커밋/푸시하지 않는다. main 반영과 v0.1.0 태그는 최종 검증 후 진행한다.
실기기 검증과 자동 테스트 결과를 구분하고 미실행 항목은 NOT RUN으로 기록한다.
